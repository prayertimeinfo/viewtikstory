TikTok Username Finder

Find a TikTok username or check whether a handle is taken.

Picking a handle for a new brand or account starts with one question: is the name free? The TikTok Username Finder checks a handle against TikTok's directory — taken, free, or belonging to an existing profile you can preview. It's also handy for tracking down an account when you remember the name only approximately. Reporters and hiring managers use it to confirm they've found the right profile before reaching out, since lookalike handles are common and the wrong one is an embarrassing mistake.

How to use it

  1. Type the username or partial name you want to check.
  2. See whether the handle exists, and preview the matching profile.
  3. If it's taken, try variations until you find a free one.

Good to know

The check covers public directory information only — it can't tell you who owns an account or reveal anything about private profiles. A handle that looks free today may be registered tomorrow; only TikTok's own signup flow confirms availability for sure. And a taken name may belong to an inactive account, which is TikTok's decision to resolve, not this tool's.
